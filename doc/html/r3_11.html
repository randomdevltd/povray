3.11 Volume Density

A medium whose density varies is a volume: smoke with a ragged edge, a flame that is brightest at its core, a column of hot air. This chapter collects what density does across the media features: how a density field scales the coefficients of a medium, how volumes combine where they overlap, how a volume bends light with refraction, and how media method 4 prepares the field for rendering. The syntax of media and density is in Media; a volume that is also a light source is described in Volume Lights. The sample scenes blend_*.pov and refraction_*.pov in scenes/interior/media are the worked examples. The examples in this chapter assume #version 4.0;.

3.11.1 Density Drives the Coefficients

A medium without a density statement has a density of 1 everywhere. With one, the density at a point is the value of the pattern there, and the medium's coefficients at that point are its keywords times that value:

absorption  at P = absorption  × density(P)
emission    at P = emission    × density(P)
scattering  at P = scattering  × density(P)    (and its extinction)
refraction  at P = refraction  × density(P)
  • The density is a colour. A pattern gives a grey from 0 to 1; a color_map or density_map can give any colour, including channels above 1, and each channel multiplies the same channel of absorption, emission and scattering. Refraction uses the mean of the channels, so it does not disperse. See Density with color_map and Density Maps and Density Lists.
  • Several density blocks in one media multiply, so only where all of them are non-zero is there any medium. Several media statements in one interior combine by their mix, which by default adds them. See Multiple Density vs. Multiple Media.
  • The pattern moves, rotates and scales with the object that holds the medium. Transformations written inside the media block apply to the density blocks written before them.
  • Any pattern is allowed, including function, density_file (see Density File) and patterns with turbulence or warp. Some cannot be prepared for method 4; see Prepared Fields.
  • A density that is negative or not finite is an error for a prepared field and for a medium that is a light. Keep densities from 0 up.

A medium with only refraction has nothing to absorb, emit or scatter: it is invisible, costs nothing in the media integration and only bends rays. One density can drive a visible medium and a refracting one together by declaring it once:

#declare Steam = density { spherical turbulence 0.4 color_map { [0 rgb 0] [1 rgb 1] } }
cylinder {
  0, y * 2, 0.5 pigment { rgbt 1 }
  interior {
    media { scattering { 1, rgb 0.6 } density { Steam } }
    media { refraction -0.03 density { Steam } }
  }
}

3.11.2 Combining Volumes

Where volumes overlap, each medium's mix says what its density does to the media ranked beneath it. The full ranking rules, the defaults by version and #default { media { mix } } are in Media Mix. For a density field the four mixes mean:

mix addThe field's absorption, emission, scattering and refraction are added to those beneath it. This is the mix of a hollow object and of every medium after the first in an interior.
mix replaceInside the object only this field, and the media ranked above it, are seen; the media beneath it are removed, whatever its density. An empty media { mix replace } clears the space.
mix subtractThe field's absorption, emission and scattering times its density are taken away from the sum beneath it, to zero in each channel, so a density that fades out carves a hollow with a soft edge. The medium itself does not show.
mix multiplyThe density scales the absorption, emission and scattering beneath it, channel by channel: 1 leaves them, 0 clears them, above 1 thickens or brightens them, and a coloured density tints them. Its own coefficients are unused.

Refraction combines by the same rules (see Refraction). Rank is set by media { priority N }, which is separate from interior { priority N }, the rank of an ior_mix replace interior (see Refraction).

Under #version 4.0; an object replaces the media beneath it by default, so a field that sits inside another one, or that is placed before a backdrop, needs mix add or a higher priority. The samples blend_carve.pov and blend_streaks.pov are shown in Worked Examples.

3.11.3 Refracting Volumes

The refraction keyword makes the index of refraction vary through space, so that light curves where the density varies: heat shimmer, mirages, steam, rocket exhaust, gradient-index lenses and the bending of light around a black hole. The formula for the index, and how refracting media combine by their mix, are under Refraction in Media Types. This section is about what the field does to rays.

3.11.3.1 The Container

A medium needs no ior of its own to refract. An object without an ior has ior off under #version 4.0;: it takes no part in refraction, has no refracting surface of its own, and the media inside it add their refraction to the index of whatever surrounds it. A refraction-only box therefore shimmers the water or air it sits in. Give the container an ior only when it should also be a solid, as a gradient-index lens is.

A surface refracts once, by the index on each side of it at the point hit. A container whose density fades to zero at its walls, with the same ior inside and out, neither refracts nor reflects there and is invisible. A density cut off by its container is a real step in the index: the surface refracts, and POV-Ray warns once where the ior on both sides is the same. Fade the density to zero at the container's surface to avoid it.

The ior on each side of a surface is what the objects holding that side give by their ior_mix, plus the media refraction there; see Refraction under Interior. Atmospheric media do not refract, and refraction in one draws a warning. Only the media of an object's interior refract.

3.11.3.2 Curved Rays

Where the index varies, camera, reflected, refracted and photon rays follow the curve in short straight chords, testing each chord for objects so that nothing embedded is skipped. Each step bends the ray by at most refraction_angle degrees (0.5 by default), judged from the curvature at its start, middle and end, so detail in the index narrower than about half a step can be missed. No step is longer than a sixty-fourth of the refracting object's size (twice the prepared resolution with method 4) or a sixteenth of the straight-line distance to the next surface.

  • A ray still inside the field after 20000 steps is taken as trapped and returns black, with a warning. Rays orbiting a strong field do this; a larger refraction_angle takes fewer steps.
  • An index driven below 0.01 by a negative refraction is held at 0.01, with a warning. Use a smaller negative coefficient or a higher ior.
  • Shadow rays and the light that scattering media receive travel straight, so shadows and lit media are not bent. Photons curve, and carry bent light into caustics and media.
  • Media with constant density do not curve rays. A constant refraction in an object of ior 1 refracts exactly as an object of ior 1 plus that constant would, apart from the radiance scaling below.
global_settings { refraction_angle 0.25 }

3.11.3.3 Brightness in a Changing Index

Absorption, emission and scattering integrate along the chords. Radiance scales with the square of the index relative to the interior's ior, so the scaling cancels when both the camera and the source sit outside refracting media, while emitting media in a raised index appear dimmer. Media emission is radiance in the units of the local index: an emission of 0.1 where the index is 1.5 above an ior of 1 looks like an emission of 0.1 / 1.5² would in an object of ior 1.5 without media refraction.

3.11.4 Prepared Fields

Media method 4, the default from #version 4.0;, evaluates the density once over a grid covering the bounding box of the container and reuses it. The one grid serves three jobs: camera rays and media shadowing (see Sampling Parameters & Methods), the index and its gradient for refraction, and the table that makes a medium a volume light.

media { method 4  resolution 0.1  scattering { 1, rgb 1 }  density { bozo } }
  • resolution is the cell width in scene units, a finite number above 0, and is an error unless the method is 4. Omitted, the width is the larger of the container's longest bounding-box side divided by 128 and the cube root of the bounding-box volume divided by 500000.
  • Each cell holds the mean of the density at eight points spread through it, and lookups interpolate between cell centres. Detail smaller than a cell can be missed; lower resolution to keep it.
  • A grid is limited to 1000000 cells. A larger one is not coarsened: the medium falls back to classic sampling with a warning that names the width that would fit. A medium light is the exception; it builds its table on coarser cells (see Volume Lights).
  • The container must be finite and bounded. The density values must be finite and not negative.
  • Block patterns (checker, brick, hexagon, cubic, square, triangular, object), average, uv_mapping and image patterns cannot be prepared. A medium that uses one keeps classic sampling, with a warning.
  • Photon propagation through media uses classic sampling.

The complete list of fallbacks, the optical-depth cache for parallel lights and the step limits are in Sampling Parameters & Methods. For a refracting field, a function density with fine detail, such as a function of distance that rises steeply near its centre, is best left to method 3, which evaluates the pattern directly; the samples that follow use it.

3.11.5 Worked Examples

All of these are in scenes/interior/media and take the options named in their first comment lines with Declare=.

3.11.5.1 Heat Shimmer

refraction_shimmer.pov lays a long box of hot air over a runway. Hot air is thinner, so the coefficient is negative. Two densities multiply: a function that is 1 inside the box and fades to 0 at its ends, sides and top, so that the box is invisible, and turbulence that makes the air wobble the distant marker board. The box has no ior, so it takes no part in refraction of its own.

box {
  <-6, -0.5, 1>, <6, 3, 58>
  pigment { rgbt 1 }
  interior {
    media {
      method 3
      refraction -0.00006
      density {
        function { max(0, min(min(1, (z - 1) / 4), min((58 - z) / 4, (6 - abs(x)) / 2)) * max(0, 1 - y / 2.6)) }
      }
      density { bozo turbulence 0.6 octaves 3 lambda 2.2 scale <1.1, 0.3, 2.5> color_map { [0 rgb 0.2] [1 rgb 1.8] } }
    }
  }
}

refraction_mirage.pov does the same with air that is thinnest at the ground and a camera standing inside the field, so grazing views curve up and the road shows the sky; it sets refraction_angle 1. refraction_plume.pov puts a sheath of hot gas with negative refraction around an emitting exhaust core.

3.11.5.2 Steam: One Density, Two Media

refraction_steam.pov declares the steam as a density and uses it twice in the interior of a cylinder: a scattering medium for the vapour you see and a refraction-only medium for the thin hot air that carries it, so the tiles behind waver where the steam rises.

interior {
  media { mix add method 3 intervals 1 samples 12 scattering { 4, rgb 3 } absorption 0.2 density { Steam } }
  media { method 3 refraction -0.03 density { Steam } }
}

refraction_lens.pov is a flat glass disc whose dissolved concentration raises its index towards the axis, a gradient-index lens: the disc has an ior, and the media add to it. refraction_portal.pov rings a portal with a torus of refracting media that is densest at the rim and fades to nothing at the torus surface.

3.11.5.3 A Black Hole

refraction_blackhole.pov lenses the stars and a glowing disk with the index of a Schwarzschild field, n(r) = (1 + rs/4r)3 / (1 − rs/4r), and nothing else. The density is the index above the field's edge divided by a cap, refraction is the cap, so that refraction × density is the index to add, and the density is 1 inside the horizon so the index stays at the cap there. Rays that graze the hole bend by a large angle, so the scene sets a small refraction_angle (Declare=Angle=A).

sphere {
  0, Reach
  pigment { rgbt 1 }
  interior {
    media {
      method 3
      refraction Most
      density {
        function { select(sqrt(x * x + y * y + z * z) - RS * 0.26, 1,
                          min(1, max(0, (Index(sqrt(x * x + y * y + z * z)) - Edge) / Most))) }
      }
    }
  }
}

3.11.5.4 Carving and Scaling Fog

blend_carve.pov carves a turbulent cloud out of turbulent fog with mix subtract. The carving medium has the fog's own coefficients, so its density is the amount of fog taken away; the second density fades the carve out towards the sphere's edge, so the hollow frays instead of cutting clean.

sphere {
  0, 1 pigment { rgbt 1 }
  interior {
    media {
      mix subtract
      scattering { 1, rgb 0.14 }
      absorption rgb <0.01, 0.015, 0.02>
      density { spherical turbulence 0.55 octaves 5 lambda 2.4 omega 0.6 color_map { [0 rgb 0] [0.25 rgb 0.6] [0.5 rgb 1.6] [1 rgb 2.5] } }
      density { spherical color_map { [0 rgb 0] [0.35 rgb 1] [1 rgb 1] } }
    }
  }
  scale <2.8, 1.9, 2.6> translate <0.2, 2.4, 1>
}

blend_streaks.pov lays a mix multiply box over uniform fog in the same bounds. Its density, a turbulent wood pattern, scales the fog beneath it, thinning it to 0.02 of its density in streaks and thickening it to 3 times between them.

box {
  <-12, 0, -10>, <12, 9, 14> pigment { rgbt 1 }
  interior {
    media {
      mix multiply
      density { wood turbulence 0.35 octaves 4 rotate x * 90 rotate z * 20 scale 2.5 color_map { [0 rgb 0.02] [0.4 rgb 0.15] [0.6 rgb 1.6] [1 rgb 3] } }
    }
  }
}

blend_lightning.pov adds a bolt and its glow to a cloud and tints the grey cloud blue with a multiply volume; blend_slime.pov stacks all four mixes in one gelatinous cube.

3.11.6 Defaults and Messages

Media defaults that matter to volumes:

density     : none (a constant density of 1)
refraction  : 0.0
mix         : see Media Mix
priority    : 0
method      : 3 from version 3.5, 4 from version 4.0 (1 before 3.5)
resolution  : automatic (method 4 only)

Global settings that act on volumes: refraction_angle (0.5), and atmospheric_ior (1.00029 from #version 4.0;, otherwise 1), which is the index outside every object.

Warnings, each given once (a prepared field that fails is reported once per field):

Media refraction changes by N across a surface at ...A refracting density is cut off at a surface with the same ior on both sides. Fade the density to zero at the container.
A ray bending through media refraction was stopped after 20000 steps ...The ray is trapped and returns black. Raise refraction_angle.
Media refraction takes the index to N at ...; it is held at 0.01.A negative refraction is too strong for the ior. Use a smaller coefficient or a higher ior.
Atmospheric media do not refract; 'refraction' works in the media of an object's interior.refraction in a scene-level media.
Media method 4 is using classic sampling: ...A prepared field was not possible; the message gives the reason, the resolution and the container bounds.

Errors: media refraction must be finite., media resolution needs a finite positive scene-unit width., media resolution requires method 4. and media priority must be an integer.
