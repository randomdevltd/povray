3.12 Surface and Volume Lights

An object can be declared a light, either from its surface or from its volume. A light block on the object (Surface Lights) makes its surface a one-sided Lambertian emitter; a light block in its interior makes its volume an emitter. Either one can also scatter on the light it receives (Bounced and Passive Lights) and is stated in nits or lumens (Brightness Units and scale_lumens). The rest of this chapter first describes the volume light.

A volume of medium can be declared a light. It lights the surfaces and scattering media around it, casts shadows shaped by its own volume, and states its own colour and brightness in a light block beside the media, separate from the glow the camera sees. A candle flame, a neon tube, a fireball, a glowing jellyfish and a lantern inside a cloud are all one interior with a light block.

This chapter describes the block, the radiance law that gives the light its power and falloff, how it is sampled, how it meets light groups, radiosity and other media, and its limits. The media themselves are described in Emission and Density Drives the Coefficients. The sample scenes light_*.pov and blend_candle.pov in scenes/interior/media are the worked examples. The examples in this chapter assume #version 4.0;.

3.12.1 Making a Volume a Light

A light statement inside an interior statement makes the object an independent volume light. The word light is matched by its text before a block, so it stays free as an identifier everywhere else. The block belongs to the interior, not to any one medium: one interior, one light, using the object's shape and its own pigment or the combined emission of its own media. An interior declared as an identifier, or copied, keeps its light.

INTERIOR_LIGHT:
  light { [INTERIOR_LIGHT_ITEM...] }
INTERIOR_LIGHT_ITEM:
  pigment { PIGMENT } | emission | brightness Value [nits | lumens] |
  attenuation { [power Value] [scale Value] [cutoff Value] } | samples Integer |
  shadowless [Bool] | media_interaction [Bool] | media_attenuation [Bool] |
  photons { [reflection Bool] [refraction Bool] } | bounce [{ passes Integer }]

Interior light default values:

pigment          : solid white
emission         : absent (use pigment)
brightness       : 1.0 nits
attenuation      : power 2, scale 1 (physical), cutoff 0.000004
samples          : 16
shadowless       : off
media_interaction: on
media_attenuation: on
pigmentThe light's own colour or pattern, evaluated in the container's coordinates. The pattern distributes emitted light independently of media density. Default solid white.
emissionA bare flag selecting the full combined RGB emission of this interior's own media, including density patterns and media mixing, as the light's emission coefficient. It takes no value and cannot be combined with pigment. Absorption, scattering and overlapping objects do not supply source colour. Unitless brightness and nits multiply the media's own emission, so brightness 1 casts the same emission coefficient the camera integrates as glow; lumens instead distribute a stated flux over it.
brightnessA non-negative source brightness. With a pigment, a unitless value and nits use the topology-normalized radiance convention below; with emission they are a plain multiplier of the media's emission; lumens specifies total generated luminous flux under the convention 1 scene unit = 1 m. See Radiance, Attenuation and Cutoff.
attenuationThe falloff: a block of a power, a scale and a cutoff, each given at most once and 2, 1 and 0.000004 by default; power 2 and scale 1 are physical. A scale of 0 turns the falloff off; a cutoff of 0 turns the cutoff off. See Radiance, Attenuation and Cutoff.
samplesAn integer of at least 1: emitter draws per lit point, and so the shadow rays. More samples give smoother soft shadows and cost more. See Sampling and Shadows.
shadowlessThe light casts no shadows, as a shadowless light does.
media_interactionWith off, the light does not light scattering media, as for a normal light source.
media_attenuationWith off, a shadow ray is not dimmed by the media it passes; see Atmospheric Attenuation.
bounceLets the interior's scattering media scatter on the light they receive and emit it as further orders. See Bounced and Passive Lights.
photonsPhoton options for the light: reflection and refraction switches, as a light source's photons block. The scene photon configuration and collecting targets remain necessary; these switches select reflected and refracted photon routes.

The block takes no position. The light is placed, transformed and copied with its object. The container must be finite. This example authors a separate visible glow; matching its colour does not make its angular radiance equal to the cast light:

sphere {
  0, 1 pigment { rgbt 1 }
  interior {
    media { emission rgb <14, 6, 1.6> * 9 density { spherical color_map { [0 rgb 0] [0.4 rgb 0.3] [1 rgb 1] } } }
    light { pigment { rgb <14, 6, 1.6> * 9 } samples 32 }
  }
  scale <0.06, 0.16, 0.06> translate <0, 1.45, 0>
}

3.12.1.1 Using Media Emission as the Source

The bare emission flag reuses the media emission field without repeating its colour or density pattern. It is available at every scene version and in .pov4. Without it, the light still defaults to solid white. For example:

interior {
  media { emission rgb <100, 40, 10> density { spherical } }
  light { emission brightness 12 lumens }
}

This generates 12 lumens using the combined RGB emission field as its distribution. The media's visible glow is unchanged. A nonzero lumen setting requires a positive source integral; absent or zero emission cannot normalize it. See scenes/interior/media/light_emission.pov.

Without a unit, or with nits, brightness is a gain on the media's emission: the light's emission coefficient is j(x) = B ε(x), where ε(x) is the combined emission of the interior's media at x and B the brightness. Nothing depends on the size or shape of the container. For example:

// the light is the glow: each point emits its media emission times brightness
sphere { 0, 0.3
  pigment { rgbt 1 }
  interior {
    media { method 4 emission rgb <4, 1.5, 0.4> density { spherical } }
    light { emission brightness 1 samples 24 }
  }
  translate y*1.5
}

casts the emission coefficient the camera integrates as the sphere's glow. brightness 2 casts twice that, without changing the glow. A pigment source is calibrated differently, as described next.

3.12.2 Radiance, Attenuation and Cutoff

The light uses its declared emitting region and source field. By default that field is its own pigment, independent of media density. With light { emission }, it is instead the full combined emission RGB of the same interior's media, after density and media mixing. Absorption, scattering, refraction and other objects do not contribute to this source field. Let V be the region's geometric volume, A its true boundary area and C(x) the selected source field. For a pigment source, unitless brightness and nits use reference length ℓ = 4V/A and isotropic emission coefficient j(x) = L C(x)/ℓ. Exposed cavity walls contribute to A; internal union seams do not. This is not a convex hull or projected silhouette normalization. The declared emitting region affects this reference calibration: padding its container while keeping a smaller pigment field unchanged is not guaranteed to preserve source strength. For an emission source, unitless brightness and nits need no reference length: j(x) = L C(x), the media's own emission coefficient times the brightness, so the container's size and padding do not change the strength.

A uniform white pigment source generates flux πLA. This is a predictable volume-source reference, not identical radiance along every chord or identical illumination at every nearby point. With no absorbing or scattering media and a white Lambertian probe of unit reflectance, a uniform unit cube gives about 0.9257L at its centre with an axis-aligned normal and 1.2399L immediately outside a face centre facing inward. A sphere gives 0.75L at its centre and L immediately outside facing inward. Geometry, receiver orientation and pigment determine actual illumination; there is no cell-sized near-distance clamp.

lumens specifies generated flux Φ, before absorption on the way out. It normalizes j(x) = ΦC(x)/(4π∫Y(C(x)) dV), where Y is the renderer's existing greyscale convention (RGB weights 0.297, 0.589 and 0.114, with white equal to one). A pattern redistributes the stated total; uniformly multiplying a nonzero pigment does not change that total. This is the renderer's established luminance convention, not a new spectral or colour-management model. A sampled zero integral cannot normalize nonzero stated lumens; a narrow source missed by preparation may also produce this diagnostic.

The volume emitter is the reference model. An authored surface emitter can be an approximation with somewhat different angular and near-field illumination; exact surface/volume identity is not promised. A transparent emitting volume is also not automatically an opaque monitor or a frosted lamp envelope. Authors choose source geometry, backing and any separate scattering diffuser to represent those objects; no geometric angular multiplier silently turns a transparent source into a diffuse surface.

For a pigment's nits, uniformly scaling geometry and receiver positions by s divides j by s, multiplies generated flux by s2, and preserves illumination. At fixed lumens, j instead scales by 1/s3 and illumination by 1/s2. To preserve the optical appearance of coexisting media, their inverse-length absorption and scattering coefficients must also scale by 1/s; resizing the same physical material is a different operation. With emission and a unitless or nits brightness, j follows the media's emission coefficient, which the author scales with the other coefficients. No light unit reads mm_per_unit. Lumens assume one scene unit is one metre; scale_lumens(Phi, c) returns Phi / c2 for author-stated metres per scene unit c.

Physical divergence follows the finite-source integral and approaches inverse-square behavior at large distance. attenuation { power Power scale Scale } adds an artistic, nonconservative path modifier. Write p for Power, a for Scale, R for the bounding radius, d for source-to-receiver path length and q = R/max(d,R). For positive a the modifier is qp−2aqp−1. The default, power 2 and scale 1, is exactly one. At distances within R it stays one; with power 2 its distant limit is 1/a. A zero scale compensates distant inverse-square divergence. Since physical divergence falls as 1/d2 far away, the far field falls as 1/dp: a power below 2 makes the light reach further. The same modifier applies to direct and photon paths. Classic fade_power and fade_distance are not accepted in this block.

cutoff leaves a light out at a lit point where the most it could add there is fainter than the cutoff, on the 0 to 1 output scale of adc_bailout: that point draws no positions from the light and traces no shadow rays to it. The bound is the light's prepared power, falling by the law above, inverse-square within R, from the nearest point of the light's bounding box, so it holds for every light, pattern and shape, and does not change when the whole scene is scaled. The default, 0.000004, is about a thousandth of the default adc_bailout: many lights that are each faint over most of a scene cost only where they are bright, and the image does not visibly change. cutoff 0 turns it off. Surface lights take the cutoff too, as attenuation { cutoff Value }, and the default applies to every surface, volume and bounced light. It applies to surface shading, media scattering, subsurface scattering and bounce preparation alike.

The medium's authored emission is appearance alone: camera, reflection and refraction rays see it, but it creates no radiosity or photon energy. Light genuinely scattered by the medium remains eligible for indirect transport. A lantern's visible glow comes from its haze scattering the light, or from an authored emission look. Use light { emission } to reuse the glow's RGB field as the light input. With nits or no unit the cast emission coefficient is then the media's own times the brightness, so brightness 1 casts the coefficient the camera integrates as glow.

3.12.2.1 The Attenuation Block

attenuation { [power Value] [scale Value] [cutoff Value] }

Each of the three items may be written once, in any order, and a light takes one block. The numbers stand inside the braces: attenuation 2 is a parse error. The defaults are the physical law and a cutoff that costs nothing visible.

powerA number greater than 0, default 2. With R the bounding radius of the light, d the path length from the source to the receiver and q = R/max(d, R), the light's physical divergence is multiplied by m = qp−2aqp−1, with p the power and a the scale. Within R the factor is 1, and far away the light falls as 1/dp: a power of 1.5 reaches further than the physical 2. Volume lights only.
scaleA number of 0 or more, default 1. The distant limit of m for power 2 is 1/a; a scale of 0 compensates the divergence, so that the light does not fall off at all. Power 2 and scale 1 give m = 1 exactly. Volume lights only.
cutoffA finite number of 0 or more, default 0.000004 (a thousandth of the default adc_bailout), 0 to turn it off. A lit point where the light could add less than this, on the 0 to 1 output scale, draws no positions from the light and traces no shadow rays to it. Surface lights, volume lights and bounced lights all take it.

The example gives a lantern whose light falls as 1/d1.5, with a cutoff ten times stricter than the default, and a panel that takes the cutoff alone, switched off:

// lantern: 400 lumens, falling as 1/d^1.5 so it reaches further, with a stricter cutoff
sphere { 0, 0.2
  pigment { rgbt 1 }
  interior { light { brightness 400 lumens attenuation { power 1.5 scale 1 cutoff 0.00001 } } }
  translate y*1.5
}
// a surface light takes the cutoff only; 0 turns it off
box { <-1, 3, -1>, <1, 3.05, 1> light { brightness 5 attenuation { cutoff 0 } } }

A surface light accepts cutoff only: power or scale in its block is the error A surface light's attenuation accepts only cutoff; power and scale are for interior lights. A surface light always follows the physical law of its geometry. fade_power and fade_distance are not items of a light block.

3.12.3 Sampling and Shadows

Preparation estimates ℓ from isotropic lines through the emitting region: occupied path length divided by the count of uninterrupted occupied intervals. Full intersection lists include cavity walls and merge internal union seams. Four independently scrambled estimates use 1024, 4096 and at most 16384 lines each, stopping when their maximum relative discrepancy is at most 0.5%. A discrepancy warning reports failure to meet that target at the limit. This is an empirical replicate check, not a certified error bound; thin geometry and narrow procedural pigment peaks can evade every preparation probe.

Preparation publishes an immutable RGB light field on the interior's shared world-space layout before tracing. Solid pigment colours remain analytic; other source fields are sampled on that layout and reconstructed by trilinear interpolation. The source geometry clips this field when light is evaluated, without masking grid nodes at curved boundaries. Runtime sampling never evaluates the authored source pattern. This sampled field approximates the authored pattern: subcell detail can be missed, so compare finer layouts for mean and shape convergence. With emission, nonlinear mixing is applied before the combined light field is interpolated, so it can differ from mixing separately interpolated media fields. The field layout may be refined by the interior's prepared-media resolution or refraction detail; changing absorption or scattering coefficients does not change the light's normalization.

Power normalization and the source proposal use this same prepared RGB target. Four independently stratified volume estimates use 163, 243 and at most 323 points each, targeting at most 0.25% relative discrepancy. Unresolved variation is reported; nonzero lumens require a positive integral. Positive nits with an unresolved power integral are rejected rather than published with zero source-selection weight. Half the position proposal remains uniform over the bounding box, preserving support of the prepared target. Every sample divides by its complete proposal probability.

At every distance, receivers integrate the finite volume rather than a centre point or a silhouette disk. Direction-and-chord sampling keeps the near field finite without a cell-distance clamp. Distant inverse-square divergence and the narrowing angular penumbra follow the same source. The samples count controls integration noise and shadow quality, not expected brightness. Increasing it costs more source evaluations and shadow rays; it is not an anti-aliasing setting.

Prepared method 4 media sample camera distance and source position jointly. For each light, samples sets the number of pairs for one geometric ray segment, shared across its numerical refraction chords and media integration calls. Each pair uses the local scattering coefficient, phase function, camera transmission and source-connection transmission, divided by both sampling probabilities. Optical depth and authored glow retain their own integration steps; refining those steps does not multiply the source-ray count. A recursive continuation through a surface starts another segment, so this is not a cap on an entire reflected or refracted ray tree. Legacy media methods 1 to 3 do not scatter a light block's light; see Light blocks and classic transport under Limits and Messages. Console statistics report collected legs, cells and attempted source pairs, plus the maximum cells per leg and an estimate of live sampling scratch space across nested legs on one render thread; allocator overhead and retained pool storage are not included.

  • Surface receivers apply their BSDF and incidence cosine. Scattering media use their scattering coefficient and phase function, without a surface cosine. Both receive the same source distribution.
  • With media_attenuation, shadow rays integrate media along the path, including media inside the emitting container. These coefficients affect transport, never source generation.
  • shadowless disables surface occlusion; media_interaction off excludes this light from scattering-media illumination.
  • Photon method 2 samples the same emission coefficient and carries physical flux; surface irradiance conversion and volume scattering use their respective transport measures.
  • Shadow rays remain straight through refracting media. Fully bent direct-light paths and the final refractive-index radiance convention remain limitations; this is not a claim of exact refractive transport.

Finite source geometry, pigment and visibility are integrated at every distance. Scene examples expose Declare=Samples=N to compare quality at different draw counts.

3.12.4 Media, Light Groups and Radiosity

An interior can also contain an independent refraction { function { DeltaN } detail D } block beside its light and coefficient media. The refraction field changes the local index without changing source generation or the media density; its detail is in scene units. A direct field function is a raw signed scalar, while the light's pigment remains a colour source.

  • The glow. The camera, reflections and refractions see authored media emission. Radiosity and photon transport exclude that appearance term while retaining light genuinely scattered by the medium; the independent light block supplies generated energy.
  • Light groups. An object with a light interior inside a light_group lights the objects of that group only, as the group's light sources do. See Light Groups.
  • Other media. With a pigment source, media mix and priority do not carve the light. With light { emission }, mixing of the source interior's own media also shapes its emission field. Overlapping objects never contribute to that source field. It is dimmed by other media only through media_attenuation.
  • Several lights. Every interior with a light block is its own light.
  • Copies. A declared object placed several times, scaled or moved, has one light per placement, and a radiance-anchored light renders the same at every scale.

3.12.5 Limits and Messages

  • Only an object's interior can hold a light. Atmospheric media cannot.
  • Media mixing affects the light source only when emission selects the interior's own media emission.
  • A light interior's photons are shot by photon method 2; photon method 1 ignores its photons block with a warning.
  • Interior and surface lights are not imaged by portals: they light what they reach directly, and a portal does not carry their light to its far mouth.
  • A light_source cannot hold a light block.
  • Light blocks and classic transport. Media methods 1 to 3 and subsurface method 1 stay exactly as they were, so they take no part in the light of a light block: they cannot make it, scatter it, bounce it or carry it beneath a surface. The parse stops at its end, with a message naming the shape, the medium or finish and the light by the lines they are written on, in three cases:
    • the interior that holds a light block also holds a method 1 to 3 medium of any kind, scattering or not (a surface light puts no such limit on its object's own media);
    • a method 1 to 3 medium that scatters, in an object or in the atmosphere, in a scene where some light block lights media (media_interaction on, the default);
    • a subsurface method 1 finish, whether it names the method or takes the scene's (method 1 before version 4.0), on an object with a light block, or on any object in a scene with a light block, since every light block lights surfaces.
    A method 1 to 3 medium that only absorbs or glows stays legal everywhere else: the light of light blocks is dimmed by it and the camera sees its glow. Use method 4 (the default from version 4.0) and subsurface method 2 (likewise) with light blocks.

For example, a method 4 medium inside the light's interior and a classic medium that only absorbs elsewhere are legal:

// a method 4 medium in a light's interior, a classic one that only absorbs elsewhere
sphere { 0, 0.3
  pigment { rgbt 1 }
  interior { media { method 4 scattering { 1, rgb 0.2 } } light { brightness 20 } }
  translate y*1.5
}
box { <-3, 0, 1>, <3, 2, 3> pigment { rgbt 1 }
  interior { media { method 3 absorption rgb 0.05 } }
}

A classic medium in the light's own interior stops the parse:

sphere { 0, 0.3
  pigment { rgbt 1 }
  interior { media { method 3 scattering { 1, rgb 0.2 } } light { brightness 20 } }
}

with The sphere light block at line L of F holds the method 3 medium at line N of F; a light block needs method 4 media. A classic scattering medium anywhere in a scene whose light lights media stops it as well, unless every light block says media_interaction off:

// the surface light lights media, so a classic scattering medium anywhere stops the parse
box { <-1, 3, -1>, <1, 3.05, 1> light { brightness 5 } }
box { <-3, 0, 1>, <3, 2, 3> pigment { rgbt 1 }
  interior { media { method 3 scattering { 1, rgb 0.05 } } }
}

// media_interaction off on the light lets a classic scattering medium stay in the scene
box { <-1, 3, -1>, <1, 3.05, 1> light { brightness 5 media_interaction off } }
box { <-3, 0, 1>, <3, 2, 3> pigment { rgbt 1 }
  interior { media { method 3 scattering { 1, rgb 0.05 } } }
}

The first gives The method 3 medium at line N of F in the box scatters, and the box light block at line L of F lights media; only method 4 media scatter a light block's light. The second is accepted.

An item of a nested block is accepted only inside its block, in both syntaxes. reflection written directly in a light block is the error 'reflection' belongs inside the photons block of a light., and the same holds for the items of other blocks:

box { <-1, 3, -1>, <1, 3.05, 1> light { brightness 5 reflection on } }

box { <-1, 3, -1>, <1, 3.05, 1> light { brightness 5 photons { reflection on } } }

3.12.6 Worked Examples

All of these are in scenes/interior/media and take the options named in their first comment lines with Declare=.

3.12.6.1 A Candle in a Misty Room

blend_candle.pov is the flame of 3.12.1 in a room filled with mist. The flame and its smoke add to the mist, so they use mix add; the mist and smoke dim the flame's light on its way to the surfaces, because media_attenuation is on. Declare=FlameLight=0 swaps the media light for a point light at the wick, to compare, FlameSamples sets the samples and FlameLumens the flame's flux in lumens, spread over its own emission.

3.12.6.2 Tubes and Neon

light_tubes.pov lights an underground passage only by fluorescent tubes and neon strips. A tube is a thin transparent cylinder with a glowing medium, and a fine resolution so the grid follows its thin shape; one tube is dying and one is dead, by the strength of the light.

cylinder {
  <0, 0, -Length / 2>, <0, 0, Length / 2>, 0.028
  pigment { rgbt 1 }
  interior { media { mix add method 4 resolution 0.009 } light { pigment { Colour * Strength } brightness 180 nits samples Samples } }
  translate P
}

3.12.6.3 Glow Inside Other Media

light_clouds.pov lets sky lanterns drift into a cumulus and light it from inside, and a flash light a storm tower from within. Each lantern is stated in lumens (Declare=LanternLumens=N, 500 by default, a large paper lantern) with attenuation { power 1.5 }, so its light falls as 1/d1.5 and reaches the cloud around it; the storm lights are stated in nits. light_explosion.pov shades a fireball's light with its own smoke and warps the street behind it with the heat. light_fish.pov makes glowing fish and jellyfish the only light in water that dims and tints it (Declare=Murk=0 clears the water); each fish uses light { emission brightness Gain }, an emission gain over its own glow (Declare=Gain=N). In each, the light is stated in its interior's light block, in nits, as a gain over the media's own emission, or in lumens, and the surrounding media act on it through media_attenuation and, for the scattering, media_interaction.

3.12.6.4 Overlapping and Contained Lights

light_intersections.pov overlaps red, green and blue lights, threads them with a bronze knot, holds a glass ball in one and crosses them with smoke; it also seals a glow in a cracked stone and sinks a pool into the floor. The lamps take a gain over their glow (Declare=LampGain=N), the stone and the pool are stated in lumens (GeodeLumens, PoolLumens). light_colonnade.pov lights a rotunda only by a glowing core at its centre, stated in lumens (Declare=CoreLumens=N), with a lens of space around it made by refraction fields (Declare=Refract=0 drops it).

3.12.7 Surface Lights

A light block placed directly on an object makes the object's surface a light. Every point of the surface emits outward with a one-sided Lambertian distribution over the object's real geometry, so a box, a mesh, a CSG shape or a stretched sphere is the lamp itself, with the soft shadows and the near and far illumination of its true shape. The block works on any object with finite surface of nonzero area, at every scene version. The word light is matched by its text before a block, so it stays free as an identifier.

SURFACE_LIGHT:
  light { [SURFACE_LIGHT_ITEM...] }
SURFACE_LIGHT_ITEM:
  pigment { PIGMENT } | emission | brightness Value [nits | lumens] |
  attenuation { cutoff Value } |
  samples Integer | shadowless [Bool] | media_interaction [Bool] |
  media_attenuation [Bool] | photons { [reflection Bool] [refraction Bool] } |
  bounce [{ passes Integer }]

Surface light default values:

pigment          : solid white
emission         : absent (use pigment)
brightness       : 1.0 nits
attenuation      : cutoff 0.000004
samples          : 16
shadowless       : off
media_interaction: on
media_attenuation: on
bounce           : absent
pigmentThe colour or pattern the surface emits, evaluated at each point of the surface. It is the light's own colour and is independent of the object's texture. Default solid white. It cannot depend on the ray or the camera, so aoi and similar patterns are rejected.
emissionA bare flag that copies the material's own emission: the object's texture pigment times its finish emission, evaluated at each point, including layered textures, texture_map and material_map patterns, UV mapping and pigment transparency between layers. It takes no value and cannot be combined with pigment. Where the material has no emission the surface emits nothing.
brightnessA finite, non-negative number, optionally followed by a unit. nits (the default) is the emitted radiance itself, per unit of the source colour. lumens states the total luminous flux. See Brightness Units and scale_lumens.
attenuationOnly cutoff: where the light could add less than this at a lit point it is left out there, as for a volume light; see Radiance, Attenuation and Cutoff. 0.000004 by default, 0 off.
samplesAn integer of at least 1: surface points drawn per lit point, and so the shadow rays. More samples give smoother soft shadows and cost more; they do not change the expected brightness.
shadowlessThe light casts no shadows, as a shadowless light does.
media_interactionWith off, the light does not light scattering media.
media_attenuationWith off, a shadow ray is not dimmed by the media it passes.
photonsreflection and refraction switches selecting the photon routes of this light, as a light source's photons block. Only photon method 2 shoots them.
bounceAdds light the surface itself scatters on. See Bounced and Passive Lights.

The light is placed, transformed and copied with its object, and takes part in light_group as any other light. An object does not light itself from a convex surface: a sphere's own light never reaches the sphere. The light does not make the object visible; the glow the camera sees is the object's own material, which is authored separately, usually with a finish emission as below.

box { <-0.6, 1, -0.05>, <0.6, 2, 0.05>
  pigment { checker rgb <0.1, 0.3, 1> rgb <1, 0.15, 0.02> scale 0.3 }
  finish { ambient 0 emission 1 diffuse 0 }
  light { emission brightness 10 nits samples 32 }
}

Here the panel's checker pattern is both what the camera sees and what lights the room. A surface light stated in lumens spreads its total flux over its whole surface, so the radiance follows from the area; scale_lumens (see Brightness Units and scale_lumens) states it for a scene drawn in another unit:

// 800 lumens spread over the panel, whatever its size
box { <-0.6, 1, -0.05>, <0.6, 2, 0.05>
  pigment { rgb 1 } finish { ambient 0 emission 1 diffuse 0 }
  light { brightness 800 lumens samples 16 }
}
// an 806 lumen panel in a scene drawn in centimetres (0.01 metre per unit)
box { <-30, 100, -2>, <30, 160, 2>
  pigment { rgb 1 } finish { ambient 0 emission 1 diffuse 0 }
  light { brightness scale_lumens(806, 0.01) lumens }
}

scenes/lights/surface_light.pov shows a bulb, a patterned screen, a strip stated in lumens and a mesh.

Not accepted in a surface light block: the attenuation power and scale (a surface light always follows the physical law of its geometry, with no artistic falloff) and fade_power or fade_distance. A light_source cannot carry a light block. A surface light combines with ordinary lights, media lights and radiosity; it does not shine through portals, see below.

Accepted: crand, fresnel and ray-dependent patterns in the material of an object whose light states its own pigment; they affect how the object looks, not what it emits. A surface light on a union that holds a portal is accepted; the portal body renders nothing and neither emits nor bounces light.

Surface and volume lights are not imaged by portals. A portal diverts the light of ordinary light sources to the far mouth; the light of an object's light block, surface or interior, lights only what it can reach directly, on the side of the portal where it stands.

3.12.8 Bounced and Passive Lights

Light normally stops at the surfaces it lights. A light block with bounce lets its own object scatter on the light that reaches it, so that a wall lit by a lamp becomes a soft light itself and a glowing fog lights its surroundings from every point of the cloud. This is light the object receives from other sources, not emission of its own.

BOUNCE:
  bounce | bounce { passes Integer }
bounceBare bounce requests one bounce order: the light the object scatters once.
passes NThe number of orders, a finite positive integer in the unsigned range (default 1). Order k is the light that the sources of order k−1 give the object, scattered again. More passes add dimmer light and cost preparation time.
box { <-1.5, -0.1, -1.5>, <1.5, 0, 1.5>
  pigment { rgb <0.8, 0.8, 0.8> } finish { ambient 0 emission 0 diffuse 0.8 }
  light { bounce { passes 2 } samples 8 }
}

A block that has bounce and no pigment or emission uses its own emission field, the surface material's emission or the interior's media emission, rather than white. An explicit input may stand before or after bounce. Zero emission stays zero. bounce and passes are matched by their text and remain free as identifiers elsewhere.

Passive sources. The wall above emits nothing of its own (its finish has emission 0): it is a passive source, which shines only the light it receives from other lights. Passive objects light a scene indirectly without an area light placed at each wall. A passive source with nothing lighting it is dark. Brightness and lumens apply to the object's authored emission only; received energy keeps its transported magnitude, so a passive source has no brightness setting to tune.

Surfaces. A surface scatters the light it receives diffusely according to its finish diffuse, brilliance and colour. Bounce does not attempt specular or mirror transport. A surface whose finish uses subsurface scattering with method 2 also sends its subsurface light on: the light that enters the object diffuses through it between the surface points and leaves from them, so a skin or wax object with a bounce block lights its neighbours with the glow that comes through it. Facing parts of one object with air between them exchange no subsurface light. This needs subsurface { method 2 } (the default from #version 4.0).

Volumes. In an interior { light { bounce } } the order is the light that the interior's scattering media scatter on, with their scattering coefficients and phase functions (isotropic, Rayleigh, Henyey-Greenstein, Mie).

sphere { 0, 1 pigment { rgbt 1 }
  interior {
    media { method 4 scattering { 1, rgb 0.3 } emission rgb 2 }
    light { emission brightness 3 lumens bounce { passes 2 } samples 8 }
  }
}

Technically, preparation advances exact scattering orders rather than feeding accumulated light back into one pass. For source l, let J0,l be authored emission and D0,l = J0,l. Order k is Dk,l = Kl[ΣmDk−1,m] while k is within that source's passes, and zero afterward. The final source is authored emission plus the sum of completed orders. A source that reaches its cutoff contributes no new order and does not emit its older orders again. Authored sources and ordinary lights enter generation zero once.

Volume bounce shares the medium's prepared spatial layout. Isotropic and Rayleigh scattering keep their angular form; Henyey-Greenstein and Mie scattering use positive per-colour weighted reservoirs bounded by samples. The diffuse source excludes glossy and ballistic transport. Source-sample visibility and extinction on the final path to a receiver are evaluated during rendering.

The progress of bounce preparation is reported in the bounce phase of the preparation progress lines.

3.12.8.2 What Bounce Costs

Bounce is prepared once, before the first pixel is traced, in the bounce phase of the preparation progress lines. A scene without it pays nothing, and the cost does not grow with the image size. Each pass is one more order, prepared after the one before it, so the cost grows with passes.

Surfaces. A bounced surface stores the light that arrives at nodes spread over its surface; where the field is read, the surface's own colour and finish are evaluated at that point, so a texture costs no nodes. The nodes are seeded once for the whole scene, at a spacing set by the total area of all bounced surfaces so that about 4096 cover it, and each order refines them level by level, down to 1/64 of that spacing. A node is split where the light it receives changes: where it differs by more than 10% from what its neighbours predict, where the two halves of its disc differ by more than 10% (a shadow edge, a contact crease) or where its light comes from closer than its spacing. A plain lit wall therefore stays close to the seed count, and nodes gather along shadow edges, creases and nearby lights. The refinement does not depend on samples, on the number of threads or on the scale of the scene. The nodes of all orders share the prepared media cell budget, each order an equal part of what is left; when it is used up, the splits that remove the most error per byte are taken first. Each order reports one console line:

Bounce o1: 3474 nodes, 1 levels, 0.23 MiB, 0.0+0.0s
Bounce o1 levels: 3474
Bounce o1 splits: between 0, within 0, near 0

with its nodes in total and per level, the memory they take, the time of the refinement and of the final pass, and how many splits each criterion asked for.

Volumes. A bounced volume is prepared on the interior's media cells with the scattering coefficients and phase functions of its media, and it counts its progress in those cells and light samples rather than in nodes. It costs more than a surface of the same size: the example above counts millions of units at the default resolution, where the surface example counts thousands. Henyey-Greenstein and Mie scattering keep reservoirs bounded by samples, so samples bounds their memory as well as their noise.

3.12.9 Brightness Units and scale_lumens

A brightness value is followed by an optional unit, written after the number; the unit words nits and lumens are read only there and stay free as identifiers.

brightness Value or brightness Value nitsRadiance in nits (candelas per square metre): the surface or volume emits Value times its source colour. Radiance is fixed, so scaling an object up by s multiplies its emitting area, and the flux it delivers, by s2, and it lights more. A volume light's emission source is already an emission coefficient, so there Value is a plain multiplier of it, unitless or in nits.
brightness Value lumensTotal generated luminous flux in lumens, before any absorption on the way out. The colour or pattern only shapes how that total is distributed. For a surface source the radiance is Value divided by π times the surface area times the grey level of the source colour (weights 0.297, 0.589 and 0.114 for red, green and blue). The flux is fixed, so scaling the object up by s divides its radiance by s2 while the illumination far from it stays the same.

Lumens assume that one scene unit is one metre. For a scene authored in another length, scale_lumens(Lumens, Metres) converts lumens stated for the real object: Metres is the number of metres in one scene unit, and the result is Lumens / Metres2, the value to write in the light block so that the object has the radiance of the real lamp at the scene's size. scale_lumens is a built-in float function with two arguments, available in classic scenes and in .pov4 scenes at every version. It needs a finite value and a positive finite number of metres; otherwise the parser reports scale_lumens takes finite lumens and a positive finite number of metres per unit. No light unit reads mm_per_unit.

// an 806 lumen lamp in a scene drawn in centimetres (0.01 metre per unit)
#declare Flux = scale_lumens(806, 0.01);
sphere { 0, 3 pigment { rgbt 1 } interior { light { brightness Flux lumens } } }
