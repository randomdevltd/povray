3.11 Volume Density

Media, refraction and volume lights are independent interior fields. Media describe absorption, scattering and visible emission. interior { refraction { ... } } changes the index field. interior { light { ... } } defines generated illumination. Changing one field's coefficients does not redefine another field.

3.11.1 Density Drives the Coefficients

A medium without density has density one. Each RGB density channel multiplies the corresponding absorption, emission and scattering coefficient. Multiple density blocks multiply. Patterns transform with their object; transformations inside a media block affect preceding density blocks. Density does not define light strength or refraction.

media {
  method 4 resolution 0.05
  absorption rgb 0.1
  scattering { 1, rgb 0.2 }
  density { bozo color_map { [0 rgb 0] [1 rgb 1] } }
}

Prepared optical density and coefficients must be finite, and extinction must be nonnegative. A configuration that cannot satisfy requested method 4 is an error, not a switch to another method.

3.11.2 Combining Volumes

Media mix add, replace, subtract and multiply combine optical coefficients according to their media priority and placement. A replacement can clear lower optical media; multiplication scales lower coefficients by its RGB density. These operations do not replace an independent refraction or light axis. An axis-only interior preserves surrounding optical media. An ordinary solid's media and optical index rules remain described under Media Mix and Interior Refraction.

3.11.3 Refracting Volumes

box {
  <-1, 0, -1>, <1, 2, 1>
  pigment { rgbt 1 } hollow
  interior {
    refraction {
      function { -0.03*max(0, 1-x*x-z*z) }
      detail 0.06
    }
  }
}

Each function { ... } returns a raw signed contribution to refractive index. All functions in a block are summed before preparation, and contributions from overlapping interiors add to the active optical ior. Values must be finite; negative values and values above one are preserved. A block requires at least one function. refraction off disables only its own interior's contribution and never clears another interior's contribution. An empty block is an error; no contribution is supplied implicitly. Transform the enclosing object to transform the functions. This syntax is available in every scene version and in both scene languages; in a scene of version 3.7 or older, refraction off keeps its classic meaning, the refraction value 0.

3.11.3.1 The Container

The container bounds the spatial field. Surface refraction uses the complete index on either side: the active optical ior plus interior field contributions. A field that jumps at its boundary can refract there as well as bend rays within it. Fade its contribution to zero at the boundary when no abrupt interface is intended. Refraction fields belong to objects, independently of coefficient media.

3.11.3.2 Curved Rays

Rays follow short chords through a changing index, testing for intersections and reintegrating boundary-crossing steps at the actual event. The world-space index gradient is derived analytically from the prepared scalar representation. refraction_angle bounds angular change. Per-field detail D is a finite positive length in scene units; omitted detail or detail auto uses bounds-derived preparation and integration controls. It does not use mm_per_unit.

The field grid samples at cell centers and interpolates between them. It is not a box average of unresolved detail: structure below the sampling scale can alias. Resolve the smallest required feature and compare finer preparation settings before relying on the result. Detail controls numerical sampling and stepping; it does not change the authored scalar field or guarantee a common mean for unresolved patterns.

3.11.3.3 Brightness in a Changing Index

Radiance transport accounts for the square of refractive index. Absorption, scattering and visible emission integrate along the curved path; their authored coefficients remain independent of the index field. A source or camera inside an index field needs the corresponding local radiance convention. A field itself neither emits nor absorbs light.

3.11.4 Prepared Fields

Each placed interior owns a shared world-space layout with independent media, light and refraction payloads. Preparation completes after final object bounds and before rendering. Snapshot-safe fields can be prepared in parallel; valid scene-dependent fields are prepared from the finalized scene. Runtime access reads published immutable data. Missing or unsupported preparation is an error, not first-pixel construction or procedural fallback.

Refraction and light always use prepared fields, regardless of the optical media method. Explicit media methods 1 through 3 retain their selected coefficient evaluation; method 4 uses prepared optical fields in camera, shadow and photon paths. Mixed media preserve each declaration without routing method 4 through an old integrator. Constant fields can use an analytic prepared representation without allocating voxel arrays; finite optical depths and continuous unbounded integration use that representation directly.

Media resolution is a positive cell width in scene units and requires method 4. prepared_media_cells limits finite preparation sizes. Fields can be coarsened to fit, with an explicit diagnostic. Finite varying fields require usable bounds. Context-dependent patterns needing a shading ray cannot define a spatial field.

3.11.5 Worked Examples

Examples are in scenes/interior/media. Their comments document their scene parameters.

3.11.5.1 Heat Shimmer

refraction_shimmer.pov and refraction_plume.pov use independent negative index contributions for warm air. The field can vary or fade without changing smoke extinction or source strength.

3.11.5.2 Steam: Independent Optical and Index Fields

#declare Steam = function { max(0, 1-x*x-z*z) }
cylinder {
  0, y*2, 0.5 pigment { rgbt 1 } hollow
  interior {
    media { scattering { 1, rgb 0.6 } density { function { Steam(x,y,z) } } }
    refraction { function { -0.03*Steam(x,y,z) } detail 0.06 }
  }
}

Reusing a declared function is an authoring choice, not coupling between the two axes.

3.11.5.3 A Black Hole

refraction_blackhole.pov demonstrates a strong positive index field. Keep indices above the renderer's positive lower limit and check integration convergence near strong gradients.

3.11.5.4 Carving and Scaling Fog

blend_carve.pov and blend_streaks.pov demonstrate optical media subtraction and multiplication. These operations affect coefficient media, not independently authored sources or refraction.

3.11.5.5 Resolved Detail

refraction_detail_bands.pov and refraction_detail_crackle.pov expose detail controls. Compare resolved grids; a finer integration step cannot recover information absent from a coarse field grid.

3.11.6 Defaults and Messages

Refraction requires one or more scalar functions, or refraction off. Detail defaults to auto; all sampled function values must be finite. Detail must be auto or positive. Preparation diagnostics identify coarsened layouts, invalid spatial contexts and unsupported bounds. An explicitly requested prepared representation is never silently replaced with a procedural or classic path.
